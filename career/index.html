  • ›OpenFGA 기반 ReBAC를 초기 설계 단계에 도입해 조직, 프로젝트, 리소스 3계층 권한을 구성. 권한 규칙 변경은 OpenFGA 모델만 고치면 반영되고, 애플리케이션 코드 수정은 새 객체 타입이나 관계를 추가할 때만 필요한 구조. 다만 운영하며 확인한 결과 서비스가 실제로 요구한 권한 규칙은 ReBAC가 필요한 수준이 아니었고, 별도 권한 서버를 함께 운영하는 비용이 그보다 컸음

  • ›배치 재실행 시 사용량 과금이 중복되지 않도록 2단계 멱등성으로 방지. 사용량 스냅샷에는 조직, 인스턴스 타입, 시각 조합의 unique 제약을, 잔액 차감 거래에는 사용 구간 기반 unique key를 적용해 이미 처리된 구간은 다시 차감하지 않음
  • ›Keycloak 기반 SSO 인증(OAuth2, OIDC) 구축. Keycloakify로 프론트엔드 스택과 일관된 커스텀 테마 적용
  • ›SQLAlchemy 2.0과 AsyncPG로 DB 접근을 비동기로 구성해 DB 대기가 다른 요청 처리를 막지 않도록 구현
  • ›인프라팀이 Prometheus로 수집하는 리소스 사용량을 API로 조회해 과금 시스템이 소비하도록 연동 구조 설계
  • ›PortOne SDK 연동 결제 시스템 구축
  • ›pytest 테스트 전략을 코드 성격별로 구분. 유틸 함수는 엣지 케이스까지 단위 테스트, 서비스 레이어는 mock 대신 실제 DB와 인프라에 연동하는 통합 테스트, CI에서는 단위 테스트만 실행
  • ›Docusaurus 기반 기술 문서 사이트(다국어, Algolia 검색) 구축과 ADR 작성으로 기술 의사결정 문서화
